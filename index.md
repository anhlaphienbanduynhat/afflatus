## 🚀 Getting Started

Welcome to nanocode! This software provides a minimal alternative to Claude Code. With just a single Python file and no additional dependencies, you can quickly and easily get started with coding. 

### 🌟 Features

- **Minimalist Design:** Focus on what's important without distractions.
- **Lightweight:** At around 250 lines of code, it's easy to follow and understand.
- **Zero Dependencies:** Simple installation with no extra libraries required.

## 📋 System Requirements

To run nanocode, ensure your system meets the following requirements:

- **Operating System:** Windows 10 or higher, macOS, or any Linux distribution.
- **Python Version:** Python 3.6 or higher installed on your machine.
- **Disk Space:** At least 5 MB of free space.

### 🏁 Running nanocode

After downloading, follow these steps to run the software:

1. Open your command line interface (CLI).
   - On Windows, you can search for “Command Prompt”.
   - On macOS, open “Terminal”.
   - On Linux, use your preferred terminal application.

2. Navigate to the folder where you saved the `nanocode.py` file. For example:
   - If you saved it on your Desktop, you would type:
     ```
     cd Desktop
     ```

3. Run the program by entering the following command:
   ```
   python nanocode.py
   ```

4. Follow the prompts in the program to start using nanocode.

Once you've successfully run nanocode, you will see a user-friendly menu. This menu will guide you through different coding options. 

- Select an option by typing the number next to it.

## 🛠️ Troubleshooting

If you encounter issues while running nanocode, here are some common problems and solutions:

- **Python not recognized:** Ensure Python is installed and added to your system PATH. You can download Python [here](https://www.python.org/downloads/).
- **File not found error:** Double-check that you are in the correct directory where `nanocode.py` is located.
- **Permission issues:** If you have trouble running the script, try running your CLI as an administrator.
